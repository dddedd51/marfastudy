# 文学史资料网页版

考研文学史复习资料的离线静态站点，纯 HTML/CSS/JS，无构建步骤，直接用浏览器打开 `index.html` 即可。

## 目录说明

| 文件 / 目录 | 内容 |
| --- | --- |
| `index.html` | 导航首页 |
| `李凡1000题_古代/现当代/外国文学史-OCR重建版.html` | 李凡 1000 题三种，支持 `#q<题号>` 深链 |
| `中国/外国文学史习题_分章刷题.html` | 分章刷题，支持 `#d<章号>` 深链 |
| `煜编考研01–06*.html` | 煜编文学考研资料分册 |
| `唐红梅外国文学知识点串讲.html` | 外国文学知识点串讲 |
| `853评论写作备考卡.html`、`创意写作_定义与特征_背诵版.html` | 853 科目卡片 |
| `百日冲刺计划.html` | 100 天打卡计划（进度存 localStorage） |
| `每日一题.html` + `每日一题.data.js` | 每日一题 |
| `番茄钟.html` | 番茄钟（背景视频在 `_shared/miku/bg/`） |
| `思维导图/` | markmap 思维导图（含 `_vendor/` 本地依赖） |
| `_shared/fonts/` | 霞鹜文楷字体 |
| `_shared/miku/` | 番茄钟背景素材 |

## 注意

- 根目录的 `.nojekyll` 必须保留。`_shared/` 以下划线开头，缺少该文件时 GitHub Pages 的 Jekyll 构建会忽略整个目录，字体和背景会全部 404。
- 页面之间使用相对路径跳转，子目录页面回跳时带 `../` 前缀，因此站点放在域名根目录或子路径下都能正常工作。
- 大体积学习视频与课件 PDF 不纳入本仓库（见 `.gitignore`）。

## 更新方式

```bash
git add -A
git commit -m "update notes"
git push
```

推送后 GitHub Pages 会自动重新构建，约 1 分钟生效。
